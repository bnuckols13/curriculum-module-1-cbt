# CBT Overview: a 45-minute group

A week-one CBT group for adults, built for telehealth and screen share.

- [Group screen](https://bnuckols13.github.io/cbt-overview-group/): check-in, three interactive diagrams (the crash example, the five-part model, the avoidance loop), a discussion board, and takeaways.
- [Dialogue guide](https://bnuckols13.github.io/cbt-overview-group/dialogue-guide.html): the facilitator's sheet, with timing and questions.

Sources: Greenberger and Padesky, *Mind Over Mood* (2nd ed., 2016); J. S. Beck, *Cognitive Behavior Therapy: Basics and Beyond* (3rd ed., 2020); Thompson-Brenner et al., *The Renfrew Unified Treatment for Eating Disorders and Comorbidity* (2021); Padesky and Kennerley, *Dialogues for Discovery* (2023).

Nothing typed on the screen is saved.
